## 🚀 使用步骤 #

1. 将 **RS232 转 USB 线**连接到电脑和梅特勒 S470 设备上。
2. 打开软件，选择正确的 **COM 端口**（可选：点击“测试连接”确保端口正确）。
3. 在 S470 设备上，依次选择 **设置 → 硬件 → 外围设备 → 打印机**。
4. 在打印机设置中，选择“**RS232 紧凑型打印机**”，取消勾选“自动波特率”，其他保持默认。
5. 点击 **“连接”** 按钮建立连接。
6. 选择采集模式（pH+电导率、pH 或 电导率）。
7. 点击 **“开始采集”** 按钮开始数据采集。
8. 在 S470 开始间隔测量方法，方法设置中务必勾选 **间隔后打印**。
9. 点击 **“停止采集”** 结束数据采集。
10. 停止试验后，开始新实验之前务必点一次 **停止采集**，否则会造成数据解析异常。
11. 点击 **“导出数据”** 按钮保存为 txt 文件。
